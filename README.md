# Realmroot Homebrew Tap

Official Homebrew packages for Realmroot command-line tools.

## Install the Realmroot CLI

```sh
brew install --cask realmroot/tap/realmroot
```

Homebrew checks the published archive checksum and installs the `realmroot`
binary. The Cask is updated automatically after a new release is published in
[`realmroot/cli`](https://github.com/realmroot/cli).
