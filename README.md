# Realmroot Homebrew Tap

Official Homebrew packages for Realmroot command-line tools.

## Install the Realmroot CLI

```sh
brew install realmroot/tap/realmroot
```

Homebrew checks the published archive checksum and installs the prebuilt
`realmroot` binary without requiring Go. The Formula supports macOS and Linux
on Intel and ARM, and is updated automatically after a new release is published in
[`realmroot/cli`](https://github.com/realmroot/cli).

## Install Enbor Runner

```sh
brew install realmroot/tap/enbor-runner
```

The Formula installs the prebuilt `enbor-runner` binary for macOS or Linux on
Intel and ARM. It is created or updated automatically after a stable Enbor
release is published in
[`realmroot/agency`](https://github.com/realmroot/agency).
