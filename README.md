# Realmroot Homebrew Tap

Official Homebrew packages for Realmroot command-line tools.

## Install the Realmroot CLI

```sh
brew install realmroot/tap/realmroot
```

Homebrew checks the published source checksum and builds `realmroot` with a
Homebrew-managed Go build dependency, so users do not need Go installed or
configured beforehand. The Formula supports macOS and Linux on Intel and ARM,
and is updated automatically after a new release is published in
[`realmroot/cli`](https://github.com/realmroot/cli).
